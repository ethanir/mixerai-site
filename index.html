How to install — 30 seconds

  1. Unzip the file you just downloaded.
  2. Open chrome://extensions in a new tab.
  3. Toggle Developer mode (top-right).
  4. Click Load unpacked (top-left), then select the chrome-mv3-prod folder.
  5. Pin MixerAI from the extensions menu and open the side panel.

Chrome may warn you it's an unpacked extension — that's expected. MixerAI isn't on the Web Store yet.
